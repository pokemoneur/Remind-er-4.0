    Step-by-step Self-Learning guide
    1. Choose Add More Data to Web/Program and select an existing profile to extend it, or choose New Program or Website to create a separate profile. New profiles can receive their first learning data in the same session.
    2. Enter the website address and click Open inside Remind-er. Sign in yourself if the site asks.
    3. Allow sharing of the page and screenshots. Allow browser control only if you want Remi to navigate for you.
    4. Choose Option A if the site is loaded in the panel. Choose Option B if you want Remi to inspect the separate browser window.
    5. Remi reviews pages and keeps your place automatically. Use Continue to inspect the next page. Pause or stop whenever you want.
    6. To save what Remi found, go to the highlighted 4. Save this batch box below and click Save this batch to guide. Wait for “Batch saved” before continuing.
    7. After the final batch is saved, click Finish site review. This marks the review complete; it does not replace the saved guide.

    Saved profiles and learned information remain in this browser or desktop profile. New batches are added to the selected profile. If the AI provider cannot connect, your session and screenshots remain saved. Fix the provider connection in Settings, then click Save this batch to guide again.
